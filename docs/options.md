# Options

With nothing set, Optio behaves as it always has. Each option on this page is
off until someone turns it on: a deployment admin in the app (the Settings
path given), or the deployment in its environment (the Helm value in
brackets). Where both exist, a value saved in the app wins over the
environment, and removing it there goes back to the environment's.

Variables without a Helm value go in `api.extraEnv` (or `existingSecrets`
for a secret one).

## Off by default: what a deployment turns on

Each change of behaviour, one by one:

| Behaviour                                                                        | Where to turn it on                                               | Environment (Helm value)                                                                                                                                                     |
| -------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| Model gateways only (no vendor keys or Bedrock)                                  | —                                                                 | `OPTIO_MODEL_ACCESS=gateway` (`modelAccess: gateway`)                                                                                                                        |
| Teams                                                                            | Settings → Access → Teams                                         | `OPTIO_TEAMS_ENABLED=true` (`teams.enabled`)                                                                                                                                 |

| Automatic merging needs the checkbox and a confirmation                          | Settings → Access → Automatic merging                             | `OPTIO_MERGE_CONFIRMATION=true` (`merge.confirmation`)                                                                                                                       |
| The getting-started guide                                                        | Settings → Access → Getting-started guide                         | `OPTIO_ONBOARDING=true` (`onboarding.enabled`)                                                                                                                               |
| Directory sync on a schedule                                                     | Settings → Access → Directory sync                                | `OPTIO_DIRECTORY_SYNC=true` (`auth.directorySync.enabled`)                                                                                                                   |

Personal and team gateway tokens, and the pre-flight that fails a run whose
gateway token is refused, apply only to work that runs through a model
gateway.

Two additions act without a switch:

- Adding a GitLab repo registers Optio's webhook on the project when
  `PUBLIC_URL` is set, so pushes, merge requests and comments reach Optio.
  `OPTIO_REPO_WEBHOOKS=none` turns that off; `github` or `all` also covers
  GitHub repos reached with a token rather than a GitHub App.
- The audit trail's daily prune keeps the action log to 365 days (the
  retention above).

## Helm defaults

With default values the chart renders the same objects as upstream's,
generated secrets and checksums aside: every value on this page that is
unset or off renders nothing. The Namespace object is rendered as before
(`createNamespace: true`); set `createNamespace: false` when something else
creates the namespace (Zarf, Rancher, `helm install --create-namespace`).
